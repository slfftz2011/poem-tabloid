
# 青春的另一种模样 —— 诗歌小报

> 一首关于沉静、坚守、自愈与默默生长的现代诗小报项目。
> 两首组队创作的现代诗，被逐行排成「青」「春」两个汉字轮廓，并置于水彩月夜背景的右上角月辉区，点题「青春」。

## 项目简介

这是一个用 **Python（python-pptx）** 从诗歌 Markdown 原稿生成 **PPT 诗歌小报** 的开源示例项目。

- 以水彩风格山野夜景图（`image1.png`）为全屏背景，16:9 铺满不留边；
- 诗一《蕨生》逐行保留全角空格占位符，排成 **「青」** 字轮廓；
- 诗二《静燃》逐行保留全角空格占位符，排成 **「春」** 字轮廓；
- 两诗并排置于背景右上角月辉区（墨色文字、留白衬托），共同点题「青春」。

字形轮廓完全由每行内部与行前的全角空格（`&#12288;` / U+3000）占位构成，脚本**不改写字句、不居中、不做自由布局**，忠实还原原稿的"建筑美"排版设计。

## 创作背景

本项目源自一次中学生现代诗创作任务（详见 `task.md`）：

> 围绕话题 **"青春的另一种模样"** 完成一首现代诗。青春不只有热烈张扬，也可以是沉静、坚守、自愈、默默生长…… 挖掘不一样的青春姿态，选用恰当意象，抒发真情，符合现代诗特点。

创作约定（摘自 `task.md`）：

- 篇幅 8–20 行，从一个新颖意象出发，构建意象群；
- 使用不寻常的修辞：博喻、铺陈、借代、夸张、通感、拟物等；
- 成品将做成小报，排版需有"建筑美"——先由图片构思，再按格子填词；
- 使用反常搭配、倒装、省略实现陌生化，不跨行；
- 押韵得当，两人组队、相互照应，诗作易于对仗。

两首诗由组队成员分别创作（《蕨生》与《静燃》），后合并为一张以「青」「春」字形点题的合璧小报。

## 两首诗

### 《蕨生》（`poem1.md`）

原始字形排版稿（全角空格构成「青」字轮廓，忠实原稿）：

```
蕨生
　　蕨生　　　
石隙藏少年锋芒
　　默长　　　
　沉敛亦作光　
　　自愈　　　
缄行胜世间喧扬
　　　　　　　
　扎根不逐浪　
　敛痛　　扛　
　蓄微光，自彰　
　守心　　望　
　淬风骨，自昂　
　静处　蕴力量
```

```
静燃

　　　雁声

似珍藏在碧天大海中的沙
　　长烟　　　一空

　青春　陪伴下　静藏
泪水　　泛起　　微光
烛光　　在此刻　　自亮
```

## 使用方法

### 依赖

- Python 3.8+
- [python-pptx](https://python-pptx.readthedocs.io/)

安装依赖：

```bash
pip install python-pptx
```

### 运行

在项目根目录执行：

```bash
python build_ppt.py
```

脚本会：

1. 读取 `poem1.md`（《蕨生》→「青」）与 `poem2_revised.md`（《静燃》→「春」）；
2. 将每行的 `&#12288;` 实体还原为全角空格 U+3000，逐行保留构成字形轮廓；
3. 以 `image1.png` 为 16:9 全屏背景，在右上角月辉区并排排布两诗；
4. 输出 `poem-tabloid.pptx`（与脚本同目录）。

### 输出

- `poem-tabloid.pptx`：16:9 幻灯片，可直接用 PowerPoint / WPS / LibreOffice 打开查看或导出打印。
